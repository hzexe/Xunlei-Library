# 项目规则
- 本项目旨在自动化的使用windows版迅雷，方向是通过wine运行它以实现比较快速的下载。
- 原理是通过--remote-debugging-port参数启动迅雷后获取调试端口，使用BaristaLabs.Skrapr库操作迅雷实现迅雷的登录、下载和任务管理.
- 下载中和已完成的列表不需要操作列，本系统不提供删除、暂停、恢复等操作；
- 测试过程中发现问题修改代码以后，需要关闭已启动的程序重新启动才能生效，否则仍然使用老文件


# 关于对Hzexe.Xunlei项目的说明
- 本项目是一个基于ASP.NET Core的Web应用程序，用于自动化的使用windows版迅雷。
- 项目的前端是一个单页应用程序，后端是一个ASP.NET Core Web API，用于处理前端的请求。
- 项目的数据库是使用迅雷的SQLite数据库，用于存储用户信息、任务信息等。
- 项目最终是以docker容器的形式运行，用户可以通过docker-compose.yml文件启动项目。
- 因为迅雷是有界面的程序，在docker容器中需要依赖wine,而显示则使用xvfb，因此，启动迅雷的时候，判断是否是linux系统，如果是，则使用xvfb-run和wine启动迅雷，否则直接启动迅雷。
- 后台向前端发送任务更新事件时，使用SignalR库实现实时更新，当任务状态发生变化时，前端会收到更新事件，从而实时更新任务列表，推送的命名为updatetask。
